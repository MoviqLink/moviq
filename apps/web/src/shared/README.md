# Shared

| Folder    | What it holds                                                    |
| --------- | ---------------------------------------------------------------- |
| `api`     | The single API client, its typed errors and latest-only requests |
| `i18n`    | English and Spanish texts, the language and the EN \| ES switch  |
| `theme`   | Light, dark or automatic, and its switch                         |
| `time`    | The page clock and how spans and instants are written            |
| `routing` | The address after `#/`, split into segments                      |
| `styles`  | Design tokens and base styles                                    |
| `ui`      | Logo, icons, the AG Grid wrapper, the traveller's header and bar |
| `journey` | Legs on the route line, New York times, fares and their order    |
| `map`     | The base map of Explore and the trip: names only, quiet colours  |
