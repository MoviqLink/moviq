# Control room pieces

Shared by the screens: `StateLabel` and `FeatureState` (icon, colour and word, never colour
alone), `AgeMeter` (the age on the route line), `LiveTime` (times that keep counting),
`ConnectionNotice` (the API is not answering, since when, and a real retry), `ReasonDialog`
(the reason asked before a sensitive action, checked with the contract's rule), `Facts` and
`SectionHead`, `PageHead` (title, tab name and focus after navigation) and `Shell` (the frame).
