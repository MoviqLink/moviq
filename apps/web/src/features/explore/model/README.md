# Explore model

- `card.ts`: signal bars, margins, speeds, courses, punctuality, ages and stop names, as the card
  writes them.
- `modes.ts`: AIS ship types by their group, minutes to a train, the days and durations of a
  possible stoppage.
- `vehicle.ts`: the next stop still ahead, the age of a report and the vehicles nearest a point.
- `shown.ts`: the modes off when Explore opens (bike share, parked scooters and bikes) and the
  modes asked of the server.
- `source.ts`: the age of a source, or the day a static file its provider dates was published,
  and that of several sources together.
- `city-now.ts`: the modes shown before any choice and one card per mode with what is followed in
  the whole city, its state and the age of its oldest usable live source.
