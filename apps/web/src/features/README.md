# Features

One folder per product feature, each with its screens, its API calls and its own styles.

| Folder     | Feature                                        |
| ---------- | ---------------------------------------------- |
| `home`     | The home page with Sara, and My trips          |
| `plan`     | Planning with Sara                             |
| `explore`  | The city live                                  |
| `credits`  | Every source, its credit and licence           |
| `trip`     | The trip watched live, with PayPal             |
| `ops`      | The control room for the MovIQ team            |
| `merchant` | The panel of the demo merchants (`#/merchant`) |
| `rewards`  | Rewards on the way and My orders (`#/rewards`) |
