# Tools

`cpu-budget.ts` (with `cpu-cases.ts`) is the CPU guard: `npm run cpu-budget -w @moviq/recorder-cf`.
`fixtures-cpu/` holds one real answer of each source, captured once on 11/11/2026 at 04:59 in
Madrid (22:59 in New York) with the common client: one request each, one a second. NYC DOT
answered `[]` then, so its file is the 15 real rows of `tests/fixtures/city/` (of 1,000).
